2. 수정 내용

- 입력 보호: 공통 useGuardedAction의 렌더 중 ref 갱신을 없애고 이벤트가 최신
  커밋의 읽기 콜백을 사용한다. 확인 시 busy 상태 재검사·취소 시 작업 미실행은 유지.
- 화면 값: 발전소/점검/초대/조직명 입력의 비교 기준은 ref 대신 React 상태로
  관리한다. 저장 완료·초기화·다른 발전소 편집 때만 기준을 갱신한다.
- 양식 ref: 기존 양식 보호 훅은 그대로 두고 반환값에서 DOM ref를 분리해 전달한다.
  이름 없는 양식·선택한 File·다른 카드의 초안을 초기화하거나 검색을 dirty로 만들지 않는다.
- 요청 수명: 기본정보·고객·설정·공개 약관·운영 이력의 초기 읽기는
  startClientRead를 사용한다. 화면 종료 시 취소, 시간 초과의 명시 실패·settle,
  동기/비동기 전송 오류, 종료/시간 초과 이후 늦은 응답 무시를 처리한다.
  쓰기를 자동 반복하지 않으며 작성 중 설정을 배경 갱신으로 덮지 않는다.
- 메뉴 URL: 역할별 허용 메뉴·UUID 검사는 유지한 채 브라우저 이력의 작은 메모리
  snapshot을 useSyncExternalStore로 구독한다. snapshot은 view/inspectionId/ready만
  포함하며 업무 자료·초안·File·토큰을 보관하지 않는다. 동일 값에는 재알림하지 않는다.
  뒤로가기 때 실제 이력 위치 복원→입력 확인→취소/명시 폐기 순서와 busy 차단 유지.
- 최신 값/의존성: 현재 메뉴 ref는 커밋 단계에서 갱신하고 요청 정리는 해당 요청
  container를 캡처한다. 소유자 분기와 점검 선택 보정의 의존성을 명시·안정화했다.
- 초기 화면: 공개 홈은 SSR 랜딩을 유지하며 브라우저 준비 뒤 콜백 여부를 한 번
  판단한다. AuthPanel은 기존 LiveApp의 클라이언트 Auth 조회 뒤에만 마운트되며
  만료 링크 메시지를 초기 상태에서 만들고 URL 정리 Effect는 state를 다시 설정하지 않는다.
- 접근성: 일정 시작/완료·사업자 번호/대표자·분석 확인 사유의 label과 실제 입력 ID를
  연결했다. 상태 안내는 block output의 기본 status 의미를 사용하고 기존 문구·레이아웃 유지.
- 감사 표시: 데이터 조회 결과를 unknown Record 강제 변환 대신 실제 열 타입으로
  추론한다. 조직 필터·허용된 사건 ID·RLS·메타데이터 미조회 원칙은 유지한다.
- 시험 도구: 쓰지 않는 import/타입/변수 선언만 없애고 원래 호출은 유지한다.
  finally의 정리 실패가 원래 시험 오류를 덮지 않게 하며 다른 정리를 계속하고
  비정상 종료값을 남긴다. 정리 실패를 CLEANED 성공으로 표시하지 않는다.
  백업 manifest의 SQL 제외는 기존과 동일하며 미사용 바인딩만 _sql로 명시했다.

3. 호환성 목적 한정 예외

lib/draft-navigation.ts의 BeforeUnloadEvent.returnValue 한 줄만
typescript/no-deprecated의 다음 줄 한정 예외로 남겼다. preventDefault와 기존
종료 보호를 함께 보존하기 위함이며 전역 규칙·파일 전체를 비활성화하지 않았다.
MDN은 preventDefault와 함께 legacy returnValue 호환 처리를 설명한다.
이 한 건을 API 제거로 해결했다고 주장하지 않는다. 구형 물리 기기 전수 시험은 하지 않았다.
https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeunload_event
