# 7개 업무 흐름 결함 보완 — 2026-10-17

범위: 사용자 승인한 7개 결함 수정. 기존 관리자/배정 전문가/승인된 의뢰인, 조직 분리, 비공개 파일, 최소 정보 사진 진단, 보고서 사진 승인·최종 발행 절차를 유지한다. 실제 회원·운영 기준·메일·요금제는 변경하지 않는다.

## 적용 내용과 확인 항목

1. **검토본 승인 식별**: 보고서 수정판과 동결 snapshot SHA-256을 화면 조회 시 함께 읽고 서버가 잠금 후 대조한다. 반려→재검토된 보고서를 과거 화면으로 승인할 수 없다. 구버전 인자 없는 호출도 우회하지 못한다. 종전 상태 전이·최종 PDF 필수·관리자 승인 규칙은 기존 내부 함수에 유지한다.
2. **분석 생명주기**: 원본별 동시 실행을 유일 인덱스/부모 잠금으로 막는다. SQL NULL 결과는 성공으로 저장하지 않는다. API 45초·쓰기 20초·확인 조회 10초로 제한하고 중단 신호를 전달한다. 성공 저장 응답이 사라지면 조회로 확인하며 결과 불명의 쓰기는 자동 반복/실패 처리하지 않는다. 10분 만료는 읽기에서 변경하지 않고 명시적 재시작 때만 이전 실행을 만료시킨다. 실행 중·미확인 실패/중단이 있으면 보고서 검토를 막고, 재분석 성공 또는 사유를 남긴 사진 직접 검토로 진행할 수 있다. 중단과 직접 검토는 별도 확인이다. 타 조직/고객은 처리할 수 없고 반복 확인은 최초 이력/시각을 보존한다.
3. **동시 잠금 순서**: 보고서 사진 등록/승인, 분석 완료/실패, PDF 보관이 점검 부모→보조 잠금→하위 행 순서를 따른다. 두 실제 PostgreSQL 세션에서 사진 승인 대기가 보조 잠금을 선점하지 않음을 확인하고, 동시 보고서 검토가 교착 없이 끝나는지 검사한다. 동시 초안 생성은 하나만 허용한다.
4. **견적 선택**: 견적·요청 수정판을 서버에서 다시 확인하고 한국 날짜 기준 만료 견적을 거부한다. 고객에게 범위·조건·시작일·유효일 전체와 선택 확인창을 제공한다. 변경 오류는 확인창 안에도 표시한다. 기존 지정 담당자·작업 시작 후 변경 금지·수수료 계산을 유지한다.
5. **발전소 편집/저장**: 다른 항목 편집/취소 전에 미저장 확인, 취소 시 입력 보존, 저장 중 전환 차단을 적용한다. 관리자 저장은 기존 RLS 안의 invoker RPC로 정확한 수정 시각을 대조하고 발전소+선택 의뢰인 연결을 한 트랜잭션으로 처리한다. 새 등록 UUID/입력 지문으로 동일 요청 재전송 시 중복을 피한다. 기존 동의·다른 metadata를 유지하고 과거 동의가 없으면 명시 동의 없이 재구성하지 않는다. 의뢰인 좁은 수정 RPC는 그대로 사용한다.
6. **전체 새로고침**: 상단 명시적 새로고침이 성공하면 독립 조회 자식 화면도 다시 조회한다. 보통 업무 저장 뒤 부모 새 조회는 자식 초안을 임의 초기화하지 않는다. 처리 중 이동 제한, 미저장 폐기 확인과 조회 실패 시 보존을 유지한다.
7. **원본 무결성**: 별도 원본 다운로드의 서버/브라우저와 재분석 전에 등록된 크기·SHA-256을 대조한다. 같은 크기 다른 바이트도 차단한다. 미리보기는 별도 파일이며 원본을 대체하지 않는다.
