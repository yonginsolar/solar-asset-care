SolarScope — 초보 사용자 탐색 검수 후 6가지 수정
날짜: 2026-10-17
기준: QA_NOVICE_EXPLORATORY_2026-10-17.txt 및 사용자의 수정·회귀 검증 승인

수정 내용

1. 관리자 점검 번호
   날짜만 쓰던 기본 번호 대신 날짜와 일회성 임의 식별값을 조합한다.
   메뉴 재방문·다른 탭에서도 새 기본 번호를 사용하며 DB의 중복 차단은 유지한다.
   사용자가 직접 적은 번호가 중복되면 한국어로 수정 방법을 안내한다.
   번호가 길 때 목록이 넘치지 않도록 표시 길이와 줄바꿈도 확인했다.

2. 로그인 후 보고서 복귀
   비로그인 보고서의 로그인 링크에 원래 보고서 경로를 보존한다.
   현재 계정·초기 비밀번호·온보딩 검사를 통과한 후에만 복귀한다.
   허용 대상은 /reports/{UUID} 한 종류이며 외부 URL·쿼리·fragment·개행은 차단한다.
   보고서 자체의 서버 Auth·조직/사용자·발행/회수 검사는 변경하지 않았다.

3. 고객 점검 열기
   현재 권한으로 조회한 점검 목록에서 선택한 요청의 상태·목적·일정·메모와
   다음 단계를 읽기 전용 상세로 보여준다. 선택 행도 강조한다.
   상세 열기 시 포커스/스크롤을 이동하되 고정 헤더 뒤에 가리지 않게 했다.
   새 요청 입력으로 이동하는 버튼과 기존 미저장/처리 중 확인을 함께 유지한다.
   고객에게 원본 업로드·전문가 판정·승인·발행 권한을 추가하지 않았다.

4. 이용 안내·문의
   공개 홈·로그인·작업공간에서 /help로 진입한다.
   요청→사진 전달→담당자 검토→발행 보고서 확인 순서와 초대/로그인 도움말을 제공한다.
   사진은 기존 관리자·전문가가 등록하며 고객은 담당자에게 원본 전달 방법을 확인한다.
   문의처는 기존 get_public_service_policy가 반환하는 공개 연락처만 표시한다.
   미등록과 조회 실패를 구분하고 실패 시 읽기만 재시도한다.
   실제 운영주체·문의처·약관을 새로 등록하거나 가상 연락처를 공개하지 않았다.

5. 입력 실패 안내
   공백 고객명/상호를 서버 요청 전에 차단한다.
   SQL 제약·권한·연결 오류를 의미에 맞는 한국어로 안내하며 실패를 성공으로 바꾸지 않는다.
   공통 오류 확인창으로 제출 위치와 무관하게 오류를 보여주고 입력을 보존한다.
   고객명 오류 확인 후에는 해당 입력란으로 돌아가며 같은 오류의 재제출도 표시한다.
   처리 중 업무 쓰기의 자동 재시도나 보안 검사 완화는 없다.

6. 잘못된 주소
   404 상태 코드를 유지하면서 한국어 설명과 홈·내 작업공간·도움말 이동을 제공한다.
   임의 history.back()이나 권한을 가정한 관리자 링크를 사용하지 않는다.
