U1 개정 분석:

- 시작·완료·중단/사진 직접 검토가 같은 조건을 사용한다.

- 기존 Auth·can_work_inspection·임대 만료·동시 실행·후보 값 검증·원자 완료·감사 기록을 유지했다.

  기존 원본 추가 보관 권한은 회수하지 않았다.

U2 일정:
- 날짜 없이 일정 확정을 선택하면 쓰기 없이 기존 일정 편집기를 열고 예정일에 포커스한다.
- 기존 update_inspection_schedule RPC의 역할·RLS·정확한 수정판·행 잠금과 감사는 유지했다.
- requested/scheduled 두 초기 상태에만 날짜 있음→scheduled, 없음→requested를 원자 반영한다.
- 다른 고급 진행 상태는 일정 수정으로 되감지 않는다.
- 별도 BEFORE INSERT/UPDATE 검사가 직접 API로도 날짜 없는 scheduled를 차단한다.
- 기존 운영 행을 일괄 재작성하거나 최초 의뢰의 날짜·경제성 자료를 필수화하지 않았다.

U3 오류 창:
- 분석 중단/수동 확인과 업체 선택의 기존 확인창 안에서 실패 문구를 표시한다.
- 같은 오류로 전역 모달을 다시 열지 않으며 오류 문단으로 포커스를 옮긴다.
- 일반 입력 화면의 공통 ErrorNotice, 권한·충돌 거부, 취소/처리 중 잠금은 유지했다.

U4 접수 후 상세:
- 성공 응답으로 받은 요청 ID를 임시 보존하고, 새 RLS 조회 결과에 그 행이 있을 때만 선택한다.

- 번호 포함 성공 안내와 해당 상세·메모를 보여주며 모바일 고정 헤더 아래로 포커스한다.
