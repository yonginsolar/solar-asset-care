R1 [P2] 다른 경로로 브라우저 앞으로가기 시 미저장 입력 유실
재현:
1. 계정·역할 관리에서 깨끗한 상태로 SolarScope 홈 이동.
2. 브라우저 뒤로가기로 계정·역할 관리 복귀.
3. 초대 양식 이름에 가상 문구 입력.
4. 일반 작업 메뉴 이동은 미저장 확인창이 뜸. '이어서 작성'으로 취소.
5. 브라우저 앞으로가기를 누르면 확인창이나 beforeunload 없이 홈으로 이동.
6. 뒤로가기로 복귀하면 입력 이름이 빈 값. 두 차례 재현.
확인 원인: lib/use-workspace-location.ts:71에서 같은 작업공간 marker가 아니거나
다른 pathname인 popstate를 바로 반환하여 라우터의 화면 교체를 허용.
영향: 해당 이력 경로를 거친 작성 중 내용이 확인 없이 사라질 수 있음.
권고: 작업공간 내부 이력뿐 아니라 다른 앱 경로로 나가는 back/forward에도
기존 dirty/busy 보호를 적용. 취소 시 실제 이력 위치·URL·입력을 함께 유지.
회귀: 정상 메뉴/홈 이동, 다른 경로 back/forward, 빠른 연속 이동, 쓰기 중 이동,
닫기/새로고침 보호를 함께 확인. 자동 저장·쓰기 재시도·권한 변경은 하지 않음.
증거: cross-route-draft-before.png / cross-route-draft-after.png

R2 [P2] 고객 신청정보 가져오기가 작성 중 등록 양식을 즉시 덮어씀
재현: 고객 관리 → 법인사업자 선택 → 상호·사업자번호·대표자 입력 →
'등록 양식에 가져오기' 클릭. 확인 없이 개인 신청정보로 네 값이 바뀌고
법인 입력칸이 사라짐. 입력값은 서버에 저장하지 않았음.
확인 원인: components/live/live-customers.tsx:504에서 기존 초안 검사 없이
setKind/setName/setBn/setRepresentative를 바로 실행.
권고: 새로 적용할 내용이 다르고 기존 초안이 있을 때만 공통 변경 확인창을
사용. 취소 시 네 값·선택·입력 위치를 보존하고, 가져오기 자체는 저장하지 않음.

입력으로 스크롤·포커스 이동. 확인 취소·동일 항목 재선택에는 불필요한 이동 금지.
